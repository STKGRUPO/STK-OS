# Proteção da branch principal

Quando o remoto oficial for criado, configure `main` com:

- pull request obrigatório;
- ao menos uma aprovação;
- checks `api` e `web` obrigatórios;
- conversas resolvidas antes do merge;
- force-push e deleção bloqueados;
- bypass restrito ao administrador do repositório.

Registrar URL do remoto e responsáveis administrativos em sistema apropriado, sem credenciais neste arquivo.
